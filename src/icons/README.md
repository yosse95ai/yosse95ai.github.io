# src/icons

astro-icon がローカル SVG を読み込むディレクトリ。`foo.svg` を置くと `local:foo` で参照できる
（リモートのレジストリから取得するのではなく、このディレクトリのファイルを読む）。

**まずアイコンセットを探し、無いものだけここに置く。**

| ロゴ | 入手元 |
|-|-|
| Kiro | `thesvg-color:kiro`（アイコンセット。背景の紫まで含まれる） |
| Dify | `local:dify`（セットにあるのは記号のみの `thesvg-color:dify` や単色の `simple-icons:dify` で、多色ワードマークは存在しないため自前） |

## ローカル SVG は「実質単色」と判定されると色を失う

astro-icon（Iconify）はローカル SVG を取り込むとき、**単色アイコンと判定した塗りを
`currentColor` に置換する**。実測（Astro 7.2.2 / astro-icon 1.2.0）:

| SVG | 取り込み後 | 判定 |
|-|-|-|
| 白 + 純黒（Kiro ロゴ） | 純黒が **`currentColor`** に置換され、テーマの文字色に追従してしまう | 白は背景扱いされ実質単色と判定される |
| `#0033FF` + 純黒（Dify ロゴ） | `#03f` と `#000` のまま保持 | 多色と判定される |

回避したい場合は純黒を避ける（`#010101` などにすると保持される）。
配布されている `thesvg-color:kiro` も目の色を `#010202` にしており、同じ回避策が取られている。

## 非正方形のロゴも扱える

`Icon.astro` は高さのみを指定し、幅は viewBox の比率から自動計算させている
（`height:{size}px; width:auto`）。そのため `dify.svg`（48×21.335）のような横長ロゴでも潰れない。

astro-icon は幅を `em` で補完する（例: `width="2.25em"`）が、`em` はフォントサイズ基準なので
px 指定の height と組み合わせると比率が崩れる。`Icon.astro` 側で CSS の `width:auto` に
上書きしているのはこのため。
